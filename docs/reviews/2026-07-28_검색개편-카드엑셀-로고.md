## 🟢 양호
- ARIA가 ECB·결정적임을 정확히 활용해 **성명 완전일치 검색을 SQL `=` 비교**로 구현(부분검색·정렬은 의도적으로 배제) — 개인정보 훑기 방지와 일관.
- 연관 테이블 검색을 **JOIN 아닌 `EXISTS` 상관 서브쿼리**로 처리해 중복행·페이징 왜곡 방지. 재사용 조각(`exCar`/`exPersonCard`/…)으로 DRY.
- **스코프 격리**: 기관차량 차량번호 검색을 `CompanySearchParam.searchCar` 플래그로 한정해 기관등록관리(공유 searchWhere) 검색 불변([TbCompanyMapper.xml](src/main/resources/mapper/TbCompanyMapper.xml)) — 실검증에서 기관등록관리는 차량번호 0건.
- 카드 엑셀 임포트가 `cardService.createCard`(행 단위 `@Transactional`)를 **프록시로 호출**해 한 행 실패가 나머지를 롤백하지 않음. 중복/필수/BiostarX 검증은 기존 등록 규칙 재사용.
- 엑셀 예시행을 `Arrays.equals(EXAMPLE_ROW)`로 걸러 실제 등록 방지 — 안전한 UX.
- 새 명명(`keywordEnc`, EXISTS 검색 패턴)과 scope(`search`,`company`)를 `docs/conventions.md`(§6/§8)에 등록 — 규칙 대장 갱신 준수.
- 인원ID 표시는 서버 detail이 이미 반환하는 `personId` 재사용(백엔드 무변경), UI 전용 변경.
- 완료분을 `docs/tasks-archive.md`에 기록.
