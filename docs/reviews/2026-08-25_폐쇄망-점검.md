## 어떻게 확인했나

정적 조사만으로는 놓칠 수 있어 **인터넷만 끊은 상태를 만들어 실제로 돌렸다.**
모든 HTTP/HTTPS 를 죽은 포트로 보내고 내부망(`192.168.*`·localhost)만 통하게 한 뒤 jar 을 기동했다.

```
java -Dhttp.proxyHost=127.0.0.1 -Dhttp.proxyPort=9 \
     -Dhttps.proxyHost=127.0.0.1 -Dhttps.proxyPort=9 \
     -Dhttp.nonProxyHosts='localhost|127.0.0.1|192.168.*' -jar cjairport.jar
```

- 기동 성공(8.7초). 로그에 `UnknownHost`·`ConnectException`·타임아웃 **0건**.
- 로그인·정규인원·임시인원·카드·감사추적 조회 모두 **200**.
- 브라우저로 **화면 11개**(정규인원·임시인원·카드·기관·차량·주차조회·설정관리·감사추적·출입권한·실시간이벤트·키오스크)를 돌며
  네트워크 요청을 가로채 확인 — 사설망 밖 요청 **0건**.

## 🟢 문제없음

- **화면 자산이 전부 내장이다** — 템플릿·JS·CSS 에 CDN·외부 폰트·분석 스크립트가 하나도 없다(624K 전량 jar 내장).
- **Java 코드에 하드코딩된 외부 주소가 없다** — 외부로 나가는 것은 adapter(BiostarX·주차)뿐이고 둘 다 내부망이다.
- **MyBatis DTD 를 받아오지 않는다** — mapper XML 18개가 `http://mybatis.org/dtd/...` 를 선언하지만,
  MyBatis 가 jar 안의 로컬 리소스로 해석한다(`XMLMapperEntityResolver`). 인터넷을 끊고 기동해 확인했다.
- **인증 음성이 파일이다** — `auth-granted.wav`·`auth-denied.wav`. 외부 TTS 를 부르지 않는다.
- **devtools 가 운영 jar 에 없다** — `developmentOnly` 로 선언돼 LiveReload 가 딸려가지 않는다.

## 🟡 확인·조치가 필요한 것

### 🟡-1 빌드는 인터넷이 필요하다 (앱이 아니라 개발 환경)
현장은 만들어진 jar 을 실행하므로 **운영에는 지장이 없다.** 다만 폐쇄망 안에서 **새로 빌드**해야 한다면 막힌다.

- Gradle 배포본(`services.gradle.org`), Maven Central, **`maven.egovframe.go.kr`** 를 받는다.
- eGovFrame 5개는 **코드에서 참조가 0건**이다(AGENTS.md 도 '미사용' 명시). 폐쇄망 빌드가 필요해지면 이것부터 걸린다.

**대응**: 폐쇄망 빌드가 요건이면 ① 사내 Maven 미러를 두거나 ② Gradle 캐시(`~/.gradle`)를 통째로 반입한다.
eGovFrame 을 계약상 유지해야 한다면 아티팩트를 사내 저장소에 올려 그쪽을 가리킨다.

### 🟡-2 자체서명 인증서 + 얼굴 촬영(웹캠)
HTTPS 인증서를 `keytool -genkeypair`(자체서명, 10년)로 만든다. 폐쇄망에서는 공인 CA 발급이 불가하니 타당한 선택이다.

문제는 **얼굴 등록이 `getUserMedia` 를 쓴다는 점**이다([face-cam.js](../../src/main/resources/static/js/web/person/face-cam.js)).
브라우저는 안전하지 않은 출처에서 카메라를 막는다. 자체서명이면 경고를 거치게 되는데, 클릭해 넘긴 뒤 카메라가 열리는지는
**브라우저·버전에 따라 다르므로 현장 PC 에서 반드시 확인해야 한다.**

**대응(권장)**: 자체서명 인증서를 **현장 PC 의 신뢰된 루트 저장소에 배포**하거나 내부 CA 로 발급한다.
그러면 경고 자체가 사라지고 카메라 문제도 없다. 인증서 SAN 에 서버 IP 를 넣는 것은 이미 문서화돼 있다.

### 🟡-3 시각 동기화(NTP)
폐쇄망은 외부 NTP 를 못 쓴다. 서버 시계가 흐르면 다음이 어긋난다.

- 정기 파기 스케줄(`0 00 03 * * *`) — 실행 시각이 밀린다.
- 출입 시작·종료 일시 — **BiostarX 장비 시계와 벌어지면** 우리가 넣은 유효기간과 장비 판정이 달라진다.
- 감사추적 시각 — 사고 조사 때 다른 로그와 대조가 어긋난다.

**대응**: 내부 NTP 서버를 두고 앱 서버·BiostarX·주차서버가 **같은 기준시**를 보게 한다.
